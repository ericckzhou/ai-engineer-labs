## The One-Sentence Brief

Take the working agent you built in **Project 08** and wrap it in an **input/output guard layer**
— scan untrusted input (user prompt **and** retrieved content) for prompt injection, redact PII
from the output, enforce an output policy, and **fail closed** at every step — then prove with a
labeled dataset that you reduced attack-catch-misses and PII leaks **without** blocking real users.

---

## Definition of Done

The project is complete when all of the following are true:

- [ ] `guards.py` implements three guards, each returning a **structured verdict** (not a bare
      bool): `scan_input`, `redact_output`, `enforce_policy`.
- [ ] `scan_input` inspects **both** user input and supplied retrieved-content, detecting
      instruction-override, role-switch, system-prompt-extraction, delimiter, and exfiltration
      patterns; returns `InputVerdict(decision, reason, matched_rule, span)`.
- [ ] `redact_output` is **detect→transform**: regex + checksum recognizers feed a config-driven
      operator (mask/replace); it does not corrupt JSON/structured payloads.
- [ ] `enforce_policy` validates the (redacted) output against the configured policy and returns a
      **fail-closed refusal** on violation *or on its own error*.
- [ ] `guarded_agent.run_guarded` composes `scan → run → redact → enforce` in that order and fails
      closed everywhere; a blocked input never reaches the agent/tools.
- [ ] Every guard **fails closed**: on exception or uncertainty, the default is refusal, never
      pass-through. (The assessable core.)
- [ ] `evaluate_guards.py` runs the labeled dataset and reports **attack-catch rate**, **benign
      false-positive rate**, and **PII leak rate** — all three.
- [ ] Guiding tests in `code/tests/` pass offline once the cores are implemented
      (`python -m pytest`); they fail with `NotImplementedError` on the starter.
- [ ] `UNDERSTANDING.md` completed before any code, stating *why a working feature is not a safe
      one*, *the data/instruction boundary*, and *what "fail closed" means*.
- [ ] `FAILURE_ANALYSIS.md` contains ≥3 intentional experiments, **including** a fail-open bug
      (remove a fail-closed default + hostile input) and an indirect-injection case (attack in
      retrieved content, not the prompt).
- [ ] `EVALUATION.md` reports the precision/recall tradeoff with all three numbers and one tuning
      move (change a threshold, show the tradeoff shift).
- [ ] `STARCALLOS_REFLECTION.md` names ≥1 concrete capability whose exposure StarcallOS must gate
      through this boundary, with a mechanism.

## Known Difficulty Spikes

1. **Fail-open is the default mistake.** A `try/except` that returns the original text "so it
   doesn't break" is the bug this project teaches. The except branch must return a *block/refusal*.
2. **Indirect injection.** If you only scan `user_input`, the `retrieved`-channel attacks all pass.
   Scan both. This is the most-missed requirement.
3. **The benign false-positive rate is half the grade.** A scanner that blocks "please ignore the
   noise in the background" (benign) because it matched "ignore" is failing precision. Tune it.
4. **Redaction vs. structure.** Masking inside a JSON value can break parsing. Redact text fields,
   not delimiters.
5. **A verdict is not a bool.** You will need the reason and the matched rule for the eval and for
   FAILURE_ANALYSIS — return them from the start.

## Debugging Approach

1. Tests first: `python -m pytest` — implement in order scan → redact → enforce → compose; each
   suite greens as you finish its core.
2. Eval: `python evaluate_guards.py` — read all three numbers. If attack-catch is high but benign-
   false-positive is also high, your rules are too broad.
3. Fail-closed probe: temporarily make a guard raise; confirm `run_guarded` returns a refusal, not
   a crash or pass-through. (Then restore.)
4. Indirect probe: move an attack string from `text` into `retrieved`; confirm it's still caught.
5. Source: re-read `source/lesson.agent.md` §4 (fail closed), §6 (detect→transform),
   `owasp-llm-top10-2025.md`, and `indirect-prompt-injection.md`.
