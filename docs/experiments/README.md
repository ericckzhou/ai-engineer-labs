# Experiments

A scratchpad for ideas that don't fit neatly into a project.

## What Goes Here

- One-off explorations of a technique
- Comparison experiments (model A vs model B)
- Quick prototypes that informed a project decision
- Failed ideas worth documenting

## Format

Each experiment is a folder:

```
experiments/
  YYYY-MM-DD-experiment-name/
    README.md       ← What you tried and what happened
    code.py         ← If there's code
```

## Experiment README Template

```markdown
# [Experiment Name]
Date: YYYY-MM-DD
Status: completed / abandoned / ongoing

## Hypothesis
What I expected to happen.

## What I Did
Steps taken.

## Result
What actually happened.

## Takeaway
What this changes about how I think.

## Applied To
Which project(s) this informed.
```
