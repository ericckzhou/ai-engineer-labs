# Skill: Repository Intelligence

**Type:** Method  
**Used by:** Architect, Curriculum Designer

## Purpose

Navigate and reason about the repo structure without reading every file.
Use catalogs, ARCHITECTURE.md, and directory listings to build a map before diving in.

## Procedure

1. Read `ARCHITECTURE.md` to understand the layer model
2. Read `OPERATING_RULES.md` for active constraints
3. Consult `catalogs/` for routing before searching files
4. Use `catalogs/concept-map.md` to find where a concept lives
5. Use `catalogs/source-map.md` to find source material
6. Read `memory/learner/skill-map.md` for learner context

## When to Use

- Before answering "where is X in this repo?"
- Before making a structural recommendation
- Before adding a new file or directory
- When the user asks for a project status overview

## Output

Concise routing map: "This concept is in X, its source is Y, the learner last engaged with it at Z."
