# Master Rubric

The universal rubric applied to every project in this curriculum.
Project-specific rubrics in `evaluations/project-criteria/` extend this with project-specific criteria.

## Dimensions

| Dimension | Weight | What It Measures |
|-----------|--------|-----------------|
| Understanding | 25% | Can the learner explain the concept accurately in their own words? |
| Implementation | 30% | Does the code work, and does it demonstrate understanding of the underlying concepts? |
| Failure Analysis | 20% | Did the learner intentionally break the system and learn from it? |
| Evaluation | 15% | Did the learner measure system quality quantitatively? |
| StarcallOS Reflection | 10% | Did the learner identify concrete patterns applicable to StarcallOS? |

## Level Anchors

### 4 — Excellent

Demonstrates mastery. Work is correct, complete, and shows insight beyond the lesson requirements.

### 3 — Good (passing threshold)

Demonstrates competency. Work is correct and complete. Minor gaps that don't affect core understanding.

### 2 — Developing

Demonstrates partial understanding. Work has significant gaps or errors. Not ready for the next project.

### 1 — Beginning

Demonstrates surface exposure only. Cannot proceed until core misunderstandings are corrected.

## Grading Notes

- The passing threshold is Level 3 overall (weighted score ≥ 75)
- A score of Level 1 in any dimension requires remediation before proceeding
- All grades go in `memory/learner/assessments/` with date and evidence
